## 3. 自动审核的**实际行为**（与站规冲突时以此为准）

| 项 | 实测结论 |
|---|---|
| 判据 | 主标题出现任意**非 Latin-1** 字符即判「主标题包含中文」。种审脚本源码：`if (/[^\x00-\xff]+/g.test(title) && …) '主标题包含中文或中文字符'; error = true;` —— 汉字、日文假名、全角标点 `『』` 都算 |
| 脚本豁免 | 同一脚本对 `cat === 408`（音乐）有 `$('#assistant-tooltips').empty(); error = false;` 豁免，但**线上后台自动审核没有照此豁免** |
| 线上证据 | #473341 / #473343（含 CJK）被拒；#473337 / #473342（纯拉丁）通过。系统消息原文：「你的种子 #N 未通过自动审核… 需要修改的地方：[list] 主标题包含中文 [/list] 请按上述提示修改后重新发布，或在本站反馈说明情况。如认为判定有误，可直接回复本消息，管理组会人工复核。」 |
| 历史一致性 | 音乐区线上 201 条标题里 88 条含中文（如「周杰伦 - … 2008-FLAC 分轨」），说明**站规/历史实践与当前自动审核互相矛盾** |
| 编辑后 | 只改 `name` 提交 `takeedit.php` 成功后，详情页 H1 已更新、`title_has_non_latin1=False`，但**仍标「禁止 · 审核不通过，原因：主标题包含中文」**：该原因字段是站点保存的审核结论，**编辑不会自动复审**，页面无复审入口 ⇒ 需回复系统消息请管理组人工复核 |
| 副标题 | 审核只查主标题：通过的两条副标题都含「专辑」等中文，未被拒 |

**代码侧已落地**：`hdkylin_site.title_has_non_latin1()` + `publish.py::run_hdkylin` 预检/提交前双闸门（宁缺勿错）；自检 46 项含阳性/阴性对照。详见 `ERR-SITE-11`。

## 4. 「种子文件名」问题：不能改、也不该改

- 站规第 13 行**禁止**转载时改文件名/文件夹结构；种审脚本源码**没有**任何文件名检查项；3 条系统消息正文**只有**「主标题包含中文」，无文件名判词。wiki 种子规则页 403（未验证）。
- 技术硬约束：改 `.torrent` 的 `info.name` 会**改变 infohash**，导致种子失效、qB 回加/跨站辅种、`handoff.verify_pieces` 逐片校验全部错位。
- ⇒ 若后台真按文件名拒种，属于站规冲突，正确处置是**回复系统消息请管理组人工复核**，不是重命名 `.torrent` / FLAC / 文件夹。

**「去哪找合规的拉丁名字」——生产库 2713 条实测**（其中 1165 条最终主标题含非 Latin-1 会被拦）：

| 来源 | 被拦条目中可用数 | 评价 |
|---|---|---|
| `log_content` 里纯 ASCII 的 `Artist / Album` 行 | 73（6.3%） | ❌ XLD/EAC log 首部也是中文（如 `黄清元 / 《金钻名曲珍藏1》`），基本帮不上 |
| `tracklist` 英文曲名 | 374（32%） | ⚠️ 曲名 ≠ 专辑名，只能辅助 |
| `opencd_descr` 官方 URL | 351（30%） | ✅ 域名/配信 slug 常含官方罗马字 |
| 品番（目录号，如 `AICL-4938`） | 43（3.7%） | ⚠️ 只能当版本标识 |
| `torrent_name` 纯 ASCII | 29（2.5%） | ⚠️ 多数带中文 |
| 双语标题含拉丁片段 | 330（28%） | ⚠️ **自动剥离会造残名**：`Max李玄 - Wanderer`→`Max - Wanderer`、`Jerorr - Заграница 2`→`Jerorr - 2`、`Various Artists - 别亦难 FLAC 1995`→`Various Artists - FLAC` |

样本观察（未做全量统计）：`.torrent` 的 `info.name` 与 FLAC 文件名也多为中文（`CD1/10不了情.flac`）。

**结论**：不造数据、不自动音译、不自动剥离。可靠路径只有「官方页面真实拼写 + 人工确认」，中文原名完整保留在副标题。
已实操的两条：`Kei Sugawara - Peacock 2026 FLAC`（官网页脚版权 + 官方配信 slug `Peacock`）、
`YUKI KANESAKA - THE GHOST IN THE SHELL O.S.T. 2026 FLAC`（动画官网 OST 页）。
