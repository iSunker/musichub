> **用途**：本项目实现 M-Team 发种/候选时的**判据来源**。原文为繁体，本文件按主题重组，措辞尽量贴近原文，不做意译发散。
> **原始归档**：`opencdhtml/M-Team 發佈規則.html`、`M-Team 候選規則.html`、`M-Team 上傳標題命名.html`、`M-Team 總則.html`、`M-Team 上傳頁 SPA 外殼.html`（来源 `wiki.m-team.cc/zh-tw/*`）。
> **核对纪律**：站规会改版，本文件记录的是抓取时的口径。涉及自动化判定前，先重抓规则页比对，不要只信本文件。
> **与 `PLAN-mteam.md` 的关系**：`PLAN-mteam.md` 记录账号资格与 API 实测结论；本文件只记录**站点规则文本**，两者不重复。

## 1. 總則（`M-Team 總則`）

1. 综合类资源站。**除入站考核外，没有任何月考/季考/年考**。
2. **保密**：任何情况下不得把与站点/管理组的沟通内容张贴到其他场所。
3. **不得在任何社群或个人公开影片中提供本站存取网址或 tracker 地址**。
4. 禁止言语攻击、禁止向趣味盒发布色情/猎奇图片。
5. 严禁利用系统漏洞。对种子有问题应**先举报种子**，不要直接评论。

> 对我们直接影响：文档、日志、代码里**不得出现站点 tracker 地址与 passkey**（与项目既有凭据红线一致）。

## 2. 發佈規則（`M-Team 發佈規則`）

### 2.1 分類怎麼選

| 分類 | 接受範圍 |
| :--- | :--- |
| Bluray | 仅蓝光原盘 / 蓝光原盘 DIY |
| Remux | 从原盘抽出的 Remux |
| HD | 压制后的高清（最低 720p） |
| SD | 压制后未达高清 |
| DVDiso | 仅 DVD 原盘 |

**无对应分类的资源一律用「其他」。**

### 2.2 影視資料連結

- 所有**电影 / 电视 / 动画 / 纪录 / 综艺**必须提供 **Douban + IMDb**；两者皆无可不填，只有一个则填一个。
- 电视剧的 IMDb 必须填 **TV Series 主页**，填单集（Episode）会被判「IMDb 链接错误」。
- **动画必须额外提供 Bangumi 链接**。

### 2.3 發佈碼（三类场景，硬性前置）

| 场景 | 要求 |
| :--- | :--- |
| 动画在 Bangumi 查无条目 | 发布前到工单系统申请发布码，副标题加一行 `發佈碼 XXXXXXXX`（空格或冒号分隔皆可） |
| 国产资源（含自拍、转录） | **一律**先申请发布码才可发布 |
| 音乐种子 > 100GB | 必须先联系管理组取得发布码（`https://ticket.m-team.io/`） |

发布码细则：

- 指名给申请人本人，填在他人发布的种子上不生效；
- **核发后 24 小时内未使用即失效**；一经使用与该种子绑定，不再过期，也不能用于第二颗；
- 只豁免「Bangumi 链接必填」一项，标题命名、mediainfo、截图数量等规则一律照常适用；
- 候选若因缺 Bangumi 链接被冻结，补上发布码后系统下一轮自动重新审核；
- 发布码只豁免系统的自动判定，**不代表已通过人工审核**。

### 2.4 種子內容規範

- **无论何种资源，发布内容中都必须附上图片**。
- 种子内容**不得包含商业网站链接、他站推广或名称**，不得含与资源无关的信息。
- 请勿另传 Sample 种子，Sample 请与正片一起上传。
- 禁止上传网游客户端。
- **本站不接受经过刮削（scrape）处理后的资源**。

### 2.5 壓縮包與檔案格式

- 除漫画、以及管理员认定应以压缩包上传的电子书/游戏/图包外，**禁止用 rar/zip/7z 上传**。
- 官方及官方合作 0day 组确有需求，讨论后可用压缩包。
- **禁止带密码的压缩包，一经发现立即删除**。

### 2.6 審核與發佈資格

- 已发布的种子适用与候选相同标准（附图、内容与标题正确），**违反者直接删除，不另行通知**。
- Software / Game 类种子**必须经过病毒扫描并审核后**才可发布。
- 直接发布的资源若不合格，**将重置发布人的发布资格**；被重置 3 次以上另予警告 1 次。
- **普通用户单种上传速度超过 1 Gbps 将触发封禁规则。**
- 合作小组资源仅允许合作小组发布。

### 2.7 轉載規範

- 不得转载正处于**禁转期**或标明**禁止转载**的资源，否则候选直接被移除，情节严重警告。
- **原资源页面所附的转载声明，新增候选时务必一并附上，否则候选不会通过。**

### 2.8 發佈內容填寫

- 主副标题见 §4；mediainfo / bdinfo 见站内《如何取得影片参数》。
- **系统可依 mediainfo 自动选择分辨率、视频编码、音频编码**，因此发种时**先填 mediainfo**。
- 视频编码适用场合：`H.264(AVC)`、`H.265(HEVC)` 用于蓝光与压制；`Xvid`、`AV1` 仅压制；`VC-1` 蓝光；`MPEG-2` DVD。

### 2.9 影片要求（逐条硬约束）

- 禁 RMVB；禁只截取部分片段转档；禁枪版（影院偷拍；未经流媒体/实体碟释出亦视为枪版）。
- 禁预告片；禁 deepfake。
- 禁低码率转高码率的 **UPSCALE**（例外见 §2.10）。
- 禁「站内已有原始影片、再经二次剪辑」的影片。
- 影片带非源站流出浮水印时，须在副标题与发布内容中说明。
- **所有影片（含蓝光原盘）必须提供完整 mediainfo 或 bdinfo**（AVS+ 除外）；多部合集只需提供其中一集，多轨信息只需主轨。
- **所有影片类种子必须加入至少 3 张、或 1x3 以上的影片内容截图**（可发布一张略缩图，但格式需 1x3 以上）。
- 所有 **AI 破解释出的影片必须勾选 AI 破解标记**。
- 中国电影及戏剧**不再强制**勾选中文字幕选项。

### 2.10 UPSCALE 例外

原则上禁止，**仅动画及里番**可申请例外，须同时满足：发布年代在 2010 年以前；该影片未曾出过 HD（720p）及以上的 WEB-DL 或圆盘。例外采**审核制**，未经允许发布即删除并警告。

### 2.11 自購自壓

- 自购需附**手写纸条**，写站内 **uid** 及「`post to mteam`」字样（uid 是用户编号不是用户名，例如 `12345 to mteam`）。
- 自压请说明参数设置，最好在 mediainfo 加自己的 tag（如 `Muxer`）。
- **自压仅接受蓝光原盘为来源**，WEB-DL、Remux 之类不接受。
- 自购自压可向管理组申请免费置顶。

### 2.12 資源包

- 官组资源包仅官组可发；合作小组资源包仅合作小组可发。
- 资源包发布后**不允许再发布其中单部**。
- 不得自行从既有资源包抽出不同小组另组资源包；影视资源未经允许不得打包多小组。
- **多季影视不允许个人多季打包**，仅允许官方多季资源包。
- 资源包不允许含站内已有资源（除非该资源已断种）；DMM Adult 不允许打包；自行整理的资源包未经允许不得发布。
- 资源包若断种，可申请删种重发。

常见问答：可转载单季/官方多季资源包；自行打包同一小组资源包需「该小组未发布过」且「非多季」；不可自行收集不同资源发「观影单」；可把官组资源包打包后发到其他站。

### 2.13 國產成人（門事件）候選辦法

- 主标题统一为 `精選國產自拍偷拍合集 Partn Mixed Pack`（n 为期数，依发布量顺延）。
- 上传前先站内信把大概截图交管理组过目；必须自行完整看过一遍；上传后两日内完成审核，按评论判定违规并推出「Rev」版。
- 提交候选后副标题标「特許資源」，直接被允许。合集包资源量**最少 20 段**；像素最低 **480**（2000 年及以前、或原始像素低于 480 者不受此限）。每人每周限申请三次。
- GAY 类型封面**禁止包含性器官**。

### 2.14 發佈後：撤種 / 轉種 / 刪種重發

**撤种**：

- 至少出现 3 个以上完成者才能撤种；无人下载则 **72 小时**后可撤；提前撤种警告 1 次。
- 做种时间超过 7 天、完成数仍少于 3 个且无人下载（无人状态需至少 24 小时），亦可撤种。
- 种子有问题应第一时间**修改主标题并举报种子**。

**转种**：同资源不同小组 / 不同视频编码 / 不同分辨率 —— **皆可发布**；同资源的资源包出现后，不可再发其中单集。

**删种重发**：

| 类型 | 定义 | 处置 |
| :--- | :--- | :--- |
| 死种 | 自**最后完成下载时间**起 **168 小时**后，已无做种者且无人下载 | 可申请删除旧种并重新发表 |
| DUPE | 站内已有重复内容**且大小一致**的种子 | 可申请删种，**留旧不留新** |

### 2.15 流量與禁發小組

- **自己发布的所有种子，其上傳流量一律以双倍计算。**
- 禁止发布的小组作品：**FGT**、**52pt**（游戏私服为例外）。

## 3. 候選規則（`M-Team 候選規則`）★ 与旧认知不同

```
候选通过达 10 种以上的用户免候选；小卒 / User 或以上等级的用戶可以新增候選。
所有候選一律經過審核，不再提供投票。
候選通過 24 小時後仍未開始做種，該候選將被移除。
發佈候選需符合標題命名規則，不符者將被凍結。
發佈候選需符合上傳規則。
中國大陸的國產影視不必再要求勾選中字選項。
所有電影 / 電視 / 動畫 / 紀錄 / 綜藝類資源，必須提供 Douban 與 IMDb 連結（兩者皆無則可不填）。
```

**候选被冻结怎么办**：

- 按管理员回复修改；修改完**必须 PM 管理员**（在下方评论回复或引用，管理员收不到提醒）。
- PM 申请解冻时**必须附上被冻结候选的链接**，不要只写「请解冻」。
- **已冻结候选逾 48 小时未处理将直接删除。**

**为什么发过 10 个种仍需候选**：违规会被重置候选数；**资源内容大小超过 100G 强制候选**；**游戏、软件分类资源强制候选**。

> ★ **与 `PLAN-mteam.md` 的冲突**：该文件记录 `/offer/config` 返回 `OFFER_MIN_VOTES=21`、`OFFER_VOTE_TIMEOUT=604800`，据此推断「需 21 票」。但规则页明确**「不再提供投票」、一律审核制**。以规则页为准，`OFFER_MIN_VOTES` 应视为接口遗留字段，**不得**再按「拉票」设计流程。
>
> ★ **推论**：本项目账号（等级 mTorrent Master，无发种权，仅 `USER_OFFER_PUBLISH`）只能走候选；候选**审核通过后 24 小时内必须开始做种**，否则被移除 —— 这是自动化必须守住的时限（对应 `OFFER_UP_TIMEOUT=86400`、`OFFER_VOTE_TIMEOUT` 之外的真实约束）。

## 4. 上傳標題命名（`M-Team 上傳標題命名`）

### 4.1 通用規則

- **主标题仅限英文（或拼音），禁止添加中文**。例外：HACG 类在管理特许下可中文；无英文名称的电影允许用其他语言原文；Adult JAV 可用原文或英文。
- 无英文名称的资源用拼音。
- **禁止加 MKV、MP4 等扩展名**。
- **禁止在主标题使用特殊符号 `! ; . # $ % :`**。
- 原种子标题未带小组名称的，请在简介说明来源。
- **括号**：除 HGame / HComic / HAnime 类、以及影片名原本含括号外，禁止在主标题加任何括号（管理员允许除外）。
- **副标题**：禁止全角标点（需获同意）；禁止添加与资源内容无关的信息（需管理员允许）。

### 4.2 視頻參數寫法（正误对照）

| 场合 | 正确 | 错误 |
| :--- | :--- | :--- |
| 压制/重编码 编码 | `x264` / `H.264` / `x265` / `H.265` | `AVC` / `HEVC` |
| 蓝光原盘及 REMUX 编码 | `AVC` / `HEVC` / `MPEG2` | `x264` / `x265` |
| 高帧率 | `HFR` | `60Fps` / `60fps` |
| 杜比视界 | `DV` / `DoVi` | `Dovi` / `DOVI` |
| 高动态范围 | `HDR` / `HDR10` / `HDR10+` / `HLG` | `hdr` / `Hdr` |

来源与类型对照：

| 来源 | 正确写法 | 错误写法 | 视频编码 | 分辨率 | 类型 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 蓝光原盘 | `BluRay` | `Blu-ray` / `BLURAY` | AVC / MPEG2 | 1080p | 蓝光原盘 |
| 蓝光原盘 4K | `UHD BluRay` | `UHD Blu-ray` | HEVC | 2160p | 蓝光原盘 |
| REMUX | `BluRay REMUX` | — | AVC / MPEG2 | 1080p | REMUX |
| 4K REMUX | `UHD BluRay REMUX` | — | HEVC | 2160p | 4K REMUX |
| BDRip | `BluRay` + `BDRip` | — | x264 / x265 | 1080p | BDRip |
| UHD 降维 BDRip | `UHD BluRay` + `BDRip` | — | x265 / H.265 | 1080p | UHD 降维 BDRip |
| 网络下载 | `WEB-DL` | `WEBDL` / `Web-DL` | H.264 / H.265 | 任意 | 网络下载 |

### 4.3 音頻參數寫法

| 格式 | 正确写法 | 备注 |
| :--- | :--- | :--- |
| Dolby Digital Plus | `DDP` | 即 EAC3，**禁止写成 EAC3** |
| DDP 全景声 | `DDP Atmos` | |
| Dolby Digital | `DD` | 即 AC3，**禁止写成 AC3** |
| TrueHD | `TrueHD` | 蓝光无损 |
| TrueHD 全景声 | `TrueHD Atmos` | |
| DTS | `DTS` | |
| DTS-HD Master Audio | `DTS-HD MA` | |
| DTS:X | `DTS-X` | |
| AAC / FLAC / LPCM / Opus | 同名 | |

- 音频**请标记声道**，如 `2.0`、`5.1`。
- 多音轨时以高码率音轨优先命名，可标注音轨数量，如 `DTS 5.1 3Audio`。

### 4.4 其他規範

- DVD 资源请在标题注明 `D5` / `D9`。
- 文件列表禁止出现 URL 等广告内容。
- **禁止标注 `HQ`、`4K` 等非标准字段**，相关说明移到副标题或简介。
- **年份**：需附加年份，位置在**标题名称之后、分辨率之前**；允许放在季数前或后。

### 4.5 各類型格式

**电影**

```
主标题：英文名称 年份 [地区/版本] 来源 解析度 视频编码 音频编码-小组名称
```

视频/音频编码前后顺序皆可；分辨率允许放来源后面；地区及版本标注（`US Cut`、`Director's Cut`）**仅限蓝光原盘**使用。

```
Moneyball 2011 BluRay 2160p HDR DoVi x265 DTS-HD MA 5.1-MTeam
Le passager de la pluie 1970 US Cut UHD BluRay 2160p HEVC DTS-HD MA2.0-MTeam
Wild City 2015 1080p CATCHPLAY WEB-DL AAC2.0 H.264-MWeb
Jason X 2001 UHD BluRay 2160p HEVC DTS-HD MA 5.1-MTeam
```

**电视**

```
主标题：英文名称 [年份] 集数 解析度 来源 视频编码 音频编码-小组名称
副标题：[年份] 其他附加资讯
```

单集/复数集须在主标题注明集数（如 `S01E01`、`S01E11-E12`）；整季合集仅标季数（`S01`），集数范围移到副标题；年份可移到副标题。

```
Best Choice Ever 2024 S01E11-E12 1080p WEB-DL x264 AAC 2.0-QHstudIo
Go Back Lover S01E19 2160p YOUKU WEB-DL AAC2.0 H.265-MWeb
  副标题：再见，怦然心动 | 2024 | 第1季第19集
Light to the Night 2026 S01E13 2160p WEB-DL HFR H.265 DTS 5.1 3Audio-UBWEB
```

**动画**

| 类型 | 格式 | 范例 |

| Encode | `英文名 年份 解析度 媒介 视频编码 音频编码-小组`（媒介可 BluRay 或 BDRip） | `Kinsou no Vermeil 2022 BDRip 1080p x265 FLAC@VCB-Studio&Nekomoe kissaten` |
| WEB 单集 | `英文名 年份 季数集数 解析度 来源 视频编码 音频编码-小组` | `Mushoku Tensei Jobless Reincarnation 2023 S02E14 1080p Baha WEB-DL x265 AAC-QHstudIo` |
| WEB 合集 | `英文名 年份 季数 解析度 来源 视频编码 音频编码-小组` | `Isekai Onsen Paradise 2024 S01 1080p Baha WEB-DL x265 AAC-QHstudIo`；`TV 01-12 Fin+SP Rev` 放副标题 |

**音乐（无损）**

```
主标题：藝人名稱 - 專輯名稱 年份 音頻編碼 整軌/分軌-小組名稱
```

## 5. 对本项目的直接影响（音乐转种视角）

| 规则点 | 我方现状 | 必须处理 |
| :--- | :--- | :--- |
| 主标题禁中文 | OpenCD 中文专辑标题本身就是中文 | 华语专辑只能走「中港澳台以中文发行可用官方中文名」例外，其余必须用英文原名 |
| 禁他站名称/推广 | 源标题带 `- OpenCD` 后缀 | **必须剥离站点名**，保留真实制作组 |
| 不带位深/采样率 | `descr.normalize_music_title()` 可能保留 `16bit`/`44.1kHz` | 新建 `build_mteam_title()`，去位深/采样率，补 `整軌`/`分軌` |
